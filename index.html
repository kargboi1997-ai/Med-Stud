Supabase Table Structure Requirement

In your Supabase SQL Editor, run this query to create the table required for data storage:

    key TEXT PRIMARY KEY,
    payload JSONB NOT NULL,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

ALTER TABLE quizlms_storage DISABLE ROW LEVEL SECURITY;
